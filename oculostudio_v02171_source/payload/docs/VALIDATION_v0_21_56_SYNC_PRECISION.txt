OculoStudio v0.21.56 Validation Report
======================================
Release: Precision-Audited Clock Synchronization
Date: 2026-11-02
Status: PASS

Problem corrected
-----------------
v0.21.55 could display 0.0 ppm drift and 0.0 ms residual after a recording had already been manually trimmed to a common start. The old local offsets were quantized to the comparison grid, and the fitted windows were also used to summarize residuals. This could make the synchronization look more exact than the evidence supported.

Implemented correction
----------------------
1. Distributed-window lags are refined below one sample by a local quadratic correlation-peak estimate.
2. Lag grid, peak width, curvature and finite local uncertainty are retained.
3. Clock drift is reported with a finite 95% confidence interval and estimator resolution.
4. Every accepted window is held out once; the affine map fitted to the remaining windows predicts that held-out offset.
5. P95 residual now means leave-one-window-out residual whenever enough windows exist.
6. A residual below estimator resolution is labelled precision-limited, not exact zero.
7. Manual co-start alignment is shown as a prior for relative offset; it does not bypass drift estimation.
8. Calibration adds a no-video evidence preview with aligned Pupil-IMU/ETM-C3D traces, local-offset trend, fitted drift and per-window holdout evidence.
9. v0.21.55 automatic TimeGraphs remain viewable but are blocked from production handoff until rerun with the v0.21.56 precision audit.
