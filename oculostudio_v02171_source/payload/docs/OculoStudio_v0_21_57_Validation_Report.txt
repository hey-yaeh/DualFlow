RELEASE PURPOSE
---------------
This release removes manual ego-video start/end entry from the normal workflow when the interaction body C3D files preserve the authoritative Vicon interval and a precision-audited Pupil↔Vicon TimeGraph already exists.

New default workflow:
  Original NRD + TSD + FaceMapper
      -> Calibration wearer assignment and precision-audited synchronization
      -> common R01/R02 body-C3D interval in Vicon time
      -> inverse role-specific TimeGraph
      -> role-specific Pupil clock interval
      -> exact NRD .time / MP4 PTS frame mapping
      -> paired immutable Native-reference trim artifacts
      -> Trim review -> Privacy -> Gaze 3D -> AOI

IMPLEMENTED BEHAVIOUR
---------------------
1. The physical interaction window is the half-open overlap of the R01 and R02 body C3D ranges.
2. R01 and R02 use their own accepted affine Pupil↔Vicon TimeGraphs; the same Vicon interval is inverted independently into each Pupil clock.
3. NRD frame boundaries are resolved from the companion .time array and actual MP4 presentation timestamps, not from time multiplied by nominal FPS.
4. The same Pupil interval is applied to TSD and FaceMapper tables.
5. R01 and R02 are published transactionally. A failure in either role rolls back both role trims and the paired clip-set artifact.
6. A new immutable aligned_clip_set artifact binds both role trims, the common Vicon interval, synchronized Calibration handoff, body C3Ds, assigned ETM C3Ds and accepted TimeGraphs.
7. The source NRD MP4 is not rewritten or re-encoded. The output is a virtual media interval, exact frame map and trimmed tables. Privacy may later create a physical encoded clip from the same frame map.
8. Manual start/end fields remain available only as a collapsed recovery workflow.
9. The main workflow order is Data -> Calibration/automatic clips -> Trim inspection -> Privacy -> Gaze 3D -> Gaze Targets.

FAIL-CLOSED GATES
-----------------
The paired job is blocked before publication when:
- a role uses a TSD other than the Timeseries source used by its accepted synchronization;
- the R01 and R02 body C3Ds have no common physical interval or insufficient overlap;
- an assigned ETM C3D cannot cover the common interval;
- a mapped Pupil interval falls outside the corresponding NRD clock beyond tolerance;
- NRD, TSD and FaceMapper do not resolve to the same Pupil recording;
- either role export fails.
