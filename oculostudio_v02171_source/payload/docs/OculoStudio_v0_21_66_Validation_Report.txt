Project workspace guarantees
============================
- Typed and pasted parent paths are validated, not treated as decorative placeholders.
- S004-S007 can be created atomically in one Project.
- Each Session receives a human-readable sessions/S### folder and isolated imports, derived, reports, annotations and cache directories.
- Sessions can be batch-added after project creation.
- Interaction IDs can be planned before source files are imported.
- ETM-A / ETM-B profiles can be applied from one source Session to selected target Sessions with parent lineage and SHA-256 provenance.
- Applying an already-shared profile is idempotent.
- Interaction-specific wearer assignment, offset, drift, TimeGraph and Trim are never copied with hardware Calibration.
- Non-empty target folders fail closed.
- Existing legacy labels such as “Session S001” remain accepted.
